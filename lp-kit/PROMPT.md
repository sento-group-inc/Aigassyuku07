# 開始プロンプト

Claude Code か Codex を開き、下の ＝＝＝ で挟まれた部分をコピーしてそのまま貼ります。書き換えるのは【】の2か所だけです。キットを手元に用意する必要はありません（AI が取ってきます）。

- 初めての人は、資料に `SAMPLE_BRIEF.md` と書くと、架空の和菓子屋で試し運転できます
- 1本の目安は30〜40分です。途中で止まったら「続けて」と返します

LP制作キットを使って、私の商品のLPを作ってください。

キット: https://github.com/sento-group-inc/Aigassyuku07/tree/main/lp-kit

## 準備（あなたがやること）

1. 作業用のフォルダで `git clone https://github.com/sento-group-inc/Aigassyuku07.git` を実行し、`Aigassyuku07/lp-kit` を作業場所にする（すでに clone 済みなら `git pull` で最新にする）
2. `lp-kit/README.md` を読み、撮影と検査に使う Playwright を README の手順で入れる
3. 手順の本体は `lp-kit/.claude/skills/lp/SKILL.md`。スキルとして呼べなければ、このファイルを読んで手順どおりに進める。ほかのスキルも、必要になったら `lp-kit/.claude/skills/` の下のファイルを読んで使う

## 私の商品

- 資料: 【商品の説明・パンフレットの文章・既存サイトのURLなどを、ここに貼るかファイルのパスを書く】
- 見た後にしてほしいこと: 【例: 無料相談の予約 / 申し込み / 資料請求。分からなければ空欄】
- 公開: まだしない。自分のパソコンのブラウザで開けるところまで

## 目指す品質

Awwwards・Webby Awards・FWA で賞を取れる水準を目指してください。基準・採点のしかた・時間の使い方は `lp-kit/QUALITY_BAR.md` にあります。標準モード（目安30〜40分）で進めてください。

- 作り始める前に `QUALITY_BAR.md` を読み、最近の Awwwards Site of the Day を1本開いて、9点の見本として撮っておく
- 「動いた」「崩れていない」で止めない。`scripts/check-lp.js` で撮影と機械検査をし、会話の履歴を持たない別の審査員に、デザイン審査員・開発者審査員・このLPの受け手の3つの視点で採点させる
- 加重平均 8.0 以上・どの項目も 7.0 以上・機械検査 ok・「署名の瞬間」（このLPにしかない印象的な1場面）を1行で言える、のすべてを満たすまで、点を下げている箇所トップ3を直して撮り直し、採点し直す。上限は3周
- 採点が返ったら、直す前に `05_QUALITY_SCORECARD.md` に点を書く。1周で点が伸びなければ、ファーストビューの構図・書体の方針・署名の瞬間のどれかを大きく作り直す
- 3周で届かなければ、点を盛らずに足りないところと次に試すことを報告して止まる
- 演出で「何の商品で、自分に何の得があるか」が分かりにくくなるなら演出を削る。実績・お客様の声・受賞歴は作らない

## 進め方

- 私に聞くのは、資料からは分からず、結論が変わる事実だけにしてください。参照サイト・技術・部品はあなたが選び、候補を出したら第一候補で先に進めてください
- 有料のサービスや動画生成を使う前には、費用を伝えて私に確認してください
- 最後に、LPのファイルのパス、最終の点数、5つの記録ファイルの場所を教えてください。開き方も1行で添えてください

## 貼ったあと

- AI が参照サイトの候補を出したら、「それでいい」か「こっちに替えて」と一言返すだけで進みます
- 3周で届かず、もっと磨きたい時は「続けて」と返すと、さらに3周回します
- 時間をかけてでも詰めたい時は、最初に「本気モードで」と書き添えます（審査員3人・上限8周、1〜2時間）
- できあがったLPを直したい時は「`akaire` で赤入れしたい」と頼むと、画面上で囲んでメモを書ける状態にしてくれます
