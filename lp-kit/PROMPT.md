# 開始プロンプト

`lp-kit` フォルダを Claude Code または Codex で開き、下の ＝＝＝ で挟まれた部分をコピーして貼ります。`【】` の中だけ書き換えてください。

＝＝＝＝＝＝＝＝＝＝ ここからコピー ＝＝＝＝＝＝＝＝＝＝

`lp` スキルを使って、次の資料からLPを作ってください。

- 資料: 【資料のファイルのパス、または商品の説明をここに貼る。試し運転なら SAMPLE_BRIEF.md】
- 見た後にしてほしいこと: 【例: 無料相談の予約 / 申し込み / 資料請求。分からなければ空欄でよい】
- 公開: まだしない。ブラウザで開けるところまで

## 目指す品質

Awwwards・Webby Awards・FWA で賞を取れる水準を目指してください。基準と採点のしかたは `QUALITY_BAR.md` にあります。

- 作り始める前に `QUALITY_BAR.md` を読み、最近の Awwwards Site of the Day を2本開いて、9点の基準を自分の目で確かめる
- 「動いた」「崩れていない」で止めない。`scripts/check-lp.js` で撮影と機械検査をし、会話の履歴を持たない別の審査員3人（デザイン審査員・開発者審査員・このLPの受け手）に採点させる
- 加重平均 8.0 以上・どの項目も 7.0 以上・機械検査 ok・「署名の瞬間」を1行で言える、のすべてを満たすまで、点を下げている箇所トップ3を直して撮り直し、採点し直すことを繰り返す
- 2周続けて点が伸びなければ、細部を磨くのをやめて、ファーストビューの構図・書体の方針・署名の瞬間のどれかを大きく作り直す
- 毎周の点と直したことを `05_QUALITY_SCORECARD.md` に残す。8周しても届かなければ、点を盛らずに足りないところを報告する
- ただし、演出で「何の商品で、自分に何の得があるか」が分かりにくくなるなら演出を削る。実績・お客様の声・受賞歴は作らない

途中で私に聞くのは、資料からは分からず、結論が変わる事実だけにしてください。参照サイト・技術・部品はあなたが選んでください。

最後に、LPのファイルのパス、最終の点数、5つの記録ファイルの場所を教えてください。
