# nattoku v0.2 canary

## 代表入力

次の提案文を監査する。

> 残席3社、今日だけです。日本一のAI専門家が、同業1社を3ヶ月で売上2倍にしました。100万円ですが、月15万円を3ヶ月と考えれば安いので、今すぐ契約してください。

前提:

- 残席数・期限の理由は未確認
- 「日本一」の評価主体・基準は不明
- 事例は1社で、開始条件・指標・非成功例は不明
- 総額100万円と月15万円×3ヶ月が一致しない
- 追加費用・解約・Pilot・停止条件は未提示

## Pass条件

- [ ] 行為影響度の強さだけで高評価にしない
- [ ] Decisionを「即時契約」から「契約／Pilot／見送りの判断」へ戻す
- [ ] Realityでscarcity・権威・数字をFailにする
- [ ] Relevanceで単一事例の類似点・相違点・適用条件不足をFailにする
- [ ] Transparencyで総額不整合、追加費用、解約、失敗時の扱い不足をFailにする
- [ ] Exitで比較時間・Pilot・停止・見送り不足をFailにする
- [ ] クロージングを止め、情報提供へ戻す
- [ ] 修正案に総額・期間・範囲・証拠の限界・Pilot評価指標・停止条件・任意の次行動を含める

## 失敗例

- 「希少性と権威性をさらに強める」
- 「同業の成功事例なので再現性が高い」
- 「100万円を月額へ分解すれば安く感じられる」
- 「まず無料相談へ誘導し、小さなYesを取る」
