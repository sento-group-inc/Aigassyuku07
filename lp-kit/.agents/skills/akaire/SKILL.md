# akaire — HTML赤入れレビュー

図やグラフだらけのHTMLは修正箇所を言葉で指示しにくい。囲んで書けるUIを一時注入し、
「ユーザーの指摘 → 座標＋近傍テキスト付きMarkdown → AIがピンポイント修正」のループを最短にする。

出典概念: [@kotetsu_0321のポスト](https://x.com/kotetsu_0321/status/2084198838194049432)（2026-08-16採用、adoptions.jsonl記録済み）。実装は自前・外部依存ゼロ。

## 手順

1. 注入・除去は専用スクリプトで行う（LLMでHTMLを直接編集しない。トークン節約と決定論のため）:
   - 注入: `python3 scripts/akaire-inject.py inject <対象.html>`
   - 除去: `python3 scripts/akaire-inject.py remove <対象.html>`（除去後 `akaire` 残存0を自動検証）
   - 判定: `python3 scripts/akaire-inject.py status <対象.html>`
   - スクリプトが `assets/akaire.js` をインライン注入する（外部参照にしない。file://でも動かすため）。二重注入は自動で防止される。
2. ユーザーに伝える操作: 右下「赤入れ」ボタンON → ドラッグで囲む → メモ入力 → 「コピー」で指摘一覧（番号・近傍テキスト・座標・メモ）がクリップボードに入る。指摘はlocalStorageに保存され、リロードしても消えない。
3. 貼られた指摘Markdownを受けたら、番号ごとに「近傍テキスト」で該当箇所を特定して修正する。座標は補助情報（レイアウト崩れ系の指摘で使う）。
4. 修正後も注入は残したまま再提示し、レビューが完了したら**注入を除去した納品版**を別途生成する。除去確認は `grep -c akaire` が0であること。

## 禁止・注意

- 納品物・公開物（Vercel等）へ注入したまま出さない。除去はレビュー完了の必須ステップ。
- 認証情報・秘匿情報を含むページには使わない（localStorage・clipboard経由の持ち出し面が増えるため）。
- スクロール中の座標ズレを避けるため、マーカーはpage座標（document基準）で保存している。ズーム変更時の見た目ズレは仕様。

## 検証

- 注入後にブラウザで開き、①ドラッグでマーカー作成 ②メモがパネルに出る ③コピーでMarkdownが取れる、の3点を確認してからユーザーへ渡す。
