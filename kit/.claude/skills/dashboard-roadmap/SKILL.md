# dashboard-roadmap — スライスに切る

## 手順

1. 完成形から逆算して、必要な作業を並べる
2. **手前で価値が出る順**に並べ替える（見える → 直せる → 増やせる → 自動化）
3. 1つを半日以内の大きさに割る
4. 各スライスに「終わりの状態」を書く
5. `docs/roadmap.md`へ書く

## 並べ方の基準

| 順番 | 種類 | 例 |
|---|---|---|
| 早い | 見える | ログインして一覧が出る、ダミーデータで1画面 |
| 中 | 直せる・増やせる | 詳細と編集、追加と削除 |
| 遅い | 賢くする | 自動計算、定期実行、通知、外部連携 |

**「いかに手前で価値が出るか」**を最優先にする。人が見て進んでいると分かることが、次の判断を早める。

## 終わりの状態

- `docs/roadmap.md`に番号付きのスライスが並んでいる
- 1番目が今日中に終わる大きさになっている
- 各スライスに「何ができるようになるか」と「終わりの状態」がある

## つまずき

| 症状 | 対処 |
|---|---|
| 1つが大きすぎる | 「本番に出す」と「見た目を整える」を分ける |
| 順番で揉める | 迷ったら「先に人が見られる方」を選ぶ |
| 全部いりそう | 今日やらないものを一覧の下へ移す（消さない） |
