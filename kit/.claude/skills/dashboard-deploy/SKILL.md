# dashboard-deploy — 本番へ出す

## 手順

1. 環境変数（Secret）をホスティングへ登録する
2. 本番ブランチへマージする
3. ビルドが走ったことを確認する
4. **発行されたURLを開く。** ログインして1画面が動くか確認する
5. 動いたURLを控える（`docs/infra.md`へ追記）

## 順序の原則

- データベースの変更は**アプリより先**に反映する
- 失敗したときは、直してからもう一度出す。押し直しを繰り返さない
- 本番のデータを消す操作は、手順に入れない

## 終わりの状態

- 本番URLを開き、ログインして1画面が動く
- URLが`docs/infra.md`に書かれている
- 次に何を足すかが`docs/roadmap.md`にある

## つまずき

| 症状 | 対処 |
|---|---|
| ビルドが失敗する | ログの**最初のエラー**を読む。複数のエラーがあっても原因は1つ |
| 画面は出るが中身が空 | 環境変数の不足か、DBにデータが無い |
| 本番だけ動かない | ローカルの`.env.local`と本番の環境変数の差分を見る |
