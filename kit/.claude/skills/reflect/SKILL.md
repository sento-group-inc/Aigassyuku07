# reflect — 振り返りを、次の自分の道具にする

たとえるなら、**料理のあとにレシピへ書き込むメモ**。「塩は半分でよかった」と書いておけば、次は最初からうまく作れる。

## いつ使うか

- 大きめの作業が終わったとき（例: 1スライスをマージした、デプロイできた）
- 遠回りしたあと、正しい道が見つかったとき
- AIに同じ注意を2回以上したとき
- 一日の終わり

小さな作業や、すでにスキルに書いてある通りに進んだだけのときは使わない。

## 手順

1. **この会話を振り返る**: 何をしようとして、どこで詰まり、何で解決したか
2. **学びを3つまで拾う**: 次も使えるものだけ。1回限りの出来事は捨てる
3. **置き場所を決める**

| 学びの種類 | 置き場所 |
|---|---|
| 画面の作り方の注意（例: 「ボタンは右下」） | `docs/ui-guidelines.md` |
| データの形の理由 | `docs/schema.md` の背景 |
| 毎回AIに言っていること | `AGENTS.md` / `CLAUDE.md` の「守る決まり」 |
| 手順そのものの改善 | 該当するスキルの `SKILL.md` |
| 残った作業 | `docs/roadmap.md` |

4. **案を見せて、選んでもらう**: 次の形で出す。**勝手に書き込まない。**

```text
1. 学び: 〈何が分かったか〉
   置き場所: 〈ファイル〉
   書き足す文: 〈実際に足す1〜2行〉
2. ...
```

5. **選ばれたものだけ書き込む**。書いたファイルを報告する。

## 終わりの状態

- 選んだ学びが、ファイルに書き込まれている
- 次に同じ作業をするとき、AIがそのファイルを読めば同じ遠回りをしない

## つまずき

| 症状 | 対処 |
|---|---|
| 学びが多すぎる | 3つに絞る。一番遠回りした所から選ぶ |
| 全部書き込みたくなる | 書くほどAIが読む量が増える。効くものだけ残す |
