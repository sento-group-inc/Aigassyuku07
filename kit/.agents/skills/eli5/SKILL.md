# eli5 — 5歳にも分かるように説明する

ELI5 は "Explain Like I'm 5" の略。**言葉は減らすが、中身の関係は減らさない。**

## 説明の型

1. **結論を1文**で言う
2. **身近なたとえを1つ**だけ使う（例: データベース＝会社の共有の棚）
3. 3つ以上のものの関係や順番があるときは、**図（Mermaid）か小さな表**にする
4. **覚えることは3つまで**に絞る

## 例

> 依頼: 「スキーマって何？」をeli5で

```text
結論: スキーマは「どの情報を、どの棚の、どの段に置くか」を決めた配置図です。

たとえ: 引っ越しの前に「本は本棚の上段、服はタンス」と決めておくと、
荷ほどきで迷いません。スキーマはその配置図です。

覚えること:
1. 画面に出る情報は、全部どこかの棚に入っている
2. 棚どうしのつながり（この案件の担当は誰か）も配置図に描く
3. 配置図を先に決めると、あとで作り直さずに済む
```

## 守ること

- 専門用語を使ったら、すぐ日常の言葉で言い換える。
- たとえは1つだけ。2つ以上混ぜると逆に分かりにくくなる。
- 正確さを犠牲にしない。たとえが当てはまらない所は「ここは違います」と言う。

## 使いどころ

| 場面 | 例 |
|---|---|
| 社内に作ったものを説明する | 「このダッシュボードで何が変わるか」 |
| 経営層に判断を仰ぐ | 「なぜこの順番で作るのか」 |
| 自分が分からない言葉に出会った | 「RLSをeli5で」 |
