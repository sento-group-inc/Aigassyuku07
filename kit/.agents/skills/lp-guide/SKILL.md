# lp-guide — 参照から作る

ゼロから考えると時間がかかる。**世の中の良い例を集めて、そこから作る。**

## 手順

1. **目的を固定する**: 誰が、何をして、どうなる画面か。主役の操作を1つ決める
2. **参照を集める**: 同じ受け手・同じ操作・同じ価格帯の実例を3つ探す（URLとスクリーンショット）
3. **何を借りるか決める**: 配置、文字の大きさ、余白、色、動きのうち、借りるものと借りないものを決める
4. **完成像を固定する**: トップと中盤1画面、スマホ幅の最低3画面を画像で決める
5. **実装する**: 借りると決めた範囲だけを自分の環境で作る
6. **見比べる**: 完成像と同じ画面幅で並べて、差分を潰す
7. **確認する**: 実際に開いて、主要な操作が動くか見る

## 守ること

- **URLと「高級感がある」だけで進めない。** 画像を開いて、何を借りるか言葉にする
- 借りたものは出典を残す（`docs/ui-guidelines.md`へ）
- 複数の方向を混ぜない。1つの基準（文字・色・余白）の下で役割分担させる

## 終わりの状態

- 参照と、借りた範囲が記録されている
- 完成像と同じ画面幅で見比べた記録がある
- 実際に開いて主要な操作が動く

## つまずき

| 症状 | 対処 |
|---|---|
| 参照が多すぎて決まらない | 目的に合う3つだけ残す |
| 真似しすぎて自社らしくない | 色と文言だけ自社に差し替える。配置は借りたまま |
| どこが違うか分からない | 同じ画面幅で並べる。並べないと分からない |
