# JEVのAPIキーを取って設定する

各社で取得します。所要5分。**キーはチャット・コード・コミット・スクリーンショットに出さないでください。**

## 1. サインイン

1. https://typesafe.ai を開く
2. 右上の `Sign In` を押す（`console.typesafe.ai/login` へ移動します）
3. `Continue with Google` か、メールアドレスを入れて `Continue`
   - メールの場合、確認コードが届きます（`Email me a code instead` でも可）

**会社のアカウントで入ってください。** 個人アカウントで入ると、あとで引き継げません。

## 2. APIキーを発行

1. サインイン後の管理画面でAPIキーを新規作成する
2. **表示は一度だけのことが多い**ので、その場でコピーする

## 3. キーを保存する（画面に出ない）

```bash
cd kit
python3 tools/jev-configure.py
```

- 入力を促されたら、コピーしたキーを貼り付けてEnter
- 入力は画面に表示されません
- 保存先は `~/.config/typesafe/api-key`（本人所有600）。上書きするときは `--replace`

## 4. 疎通を確認する

```bash
python3 tools/jev-configure.py --verify
```

`接続に成功しました。`と、確率付きの答えが出れば完了です。うまくいかないときは下の表を見てください。

| 症状 | 対処 |
|---|---|
| HTTP 401 / 403 | キーの値が正しいか。契約状態が有効か |
| HTTP 429 | 短期間に呼びすぎ。少し待つ |
| `APIへ接続できませんでした` | ネットワーク。社内プロキシの可能性 |
| キーが分からなくなった | 管理画面で作り直し、`--replace`で入れ直す |

## 5. 何に使うかを知る

JEVは文章を書くAIではなく、**判断するAI**です。返ってくるのは選択・点数・確率で、そのままプログラムの分岐に使えます。

| 型 | 返るもの | 例 |
|---|---|---|
| choice | 選んだ1つと各候補の確率 | この問い合わせはどの担当か |
| score | 段階の値と分布 | 緊急度はどのくらいか |
| noul | 0〜1の確率 | この内容は外に出してよいか |

使い方の詳細は `.claude/skills/jev-guide/SKILL.md` にあります。
