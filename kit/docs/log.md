# 開発ログ

> 要望・気づき・決定・詰まりを、出たその場で1行ずつ足していく。**AIは作業前にこのファイルを読む。**
> 会話やAIの記憶は、モデルを替えたりセッションが切れたりすると消える。消えて困ることは全部ここに書く。

## 書き方

`- 日付 [種類] 内容（理由・出どころ）`

種類: 要望 / 気づき / 決定 / 詰まり / 済

## ログ

- （例）2026-10-06 [要望] 担当者ごとの件数を一覧の上に出したい（営業部長から）
- （例）2026-10-06 [決定] 見積金額は万円単位で持つ（円単位が要る業務がないため）
- （例）2026-10-06 [詰まり] 一覧の並び順を変えると保存されない → MVPなので研究で扱う
