当日の手順

  1. エージェントを起動する

    サインインは事前準備で済んでいる前提です。起動できることだけ確認します。

  2. キットをcloneする

    git clone https://github.com/sento-group-inc/Aigassyuku07.git
cd Aigassyuku07/kit

  3. 足りないものを確認する

    ./setup.sh

    何もインストールしません。足りないものと入手先URLを表示するだけです。NGが出たらURLから入れて、もう一度実行します。

  4. 外部サービスの準備状況を見る

    ./setup.sh --check-services

    JEV・GitHub・Supabase・Vercelのどれが済んでいて、どれが残っているかを一覧で出します。

  5. JEVのAPIキーを取って設定する

    JEVのページの手順で取得します。各社で取得してください。取得後の設定はキットのスクリプトで行います。

    python3 tools/jev-configure.py

    キーはチャットに貼らないでください。スクリプトは入力した値を画面に表示せず、そのまま保存します。

  6. キットをエージェントで開く

    Aigassyuku07/kitをフォルダとして開きます。ここが今日の作業場所です。

    Claudeを使う人の場合: Claude Codeで同じフォルダを開きます。kit/CLAUDE.mdが読まれ、kit/.claude/skills/のスキルが使えます。

  7. 最初のプロンプトを送る

    リポジトリ直下のPROMPT.mdの「最初に貼るもの」をコピーして送ります。
