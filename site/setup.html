次の一手: GitHubへサインインする。

使うスキル: `guide`

あなたがやること:

1. このフォルダのターミナルで `gh auth login` を実行
2. `GitHub.com` → `HTTPS` → `Login with a web browser` を選択
3. 表示されたURLをブラウザで開き、コードを入力して「Authorize GitHub CLI」を押す
4. 終わったら `./setup.sh --check-services` を実行
