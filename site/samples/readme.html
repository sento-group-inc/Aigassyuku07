誰できること
営業自分の案件が、見積・契約・着工のどこにいるか一目で分かる
現場監督今週着工する案件と、資材の手配漏れが分かる
社長止まっている案件（7日以上動きなし）にすぐ気づける

今回は作らないもの

CONTEXT.md

リフォーム案件ボード

Language

案件: お客様1件の1回のリフォーム工事。問い合わせから引き渡しまで。
避ける: 物件、工事、ジョブ

状況: 案件が今いる段階。問い合わせ／見積中／契約済／着工／引き渡し済 のどれか1つ。
避ける: ステータス、進捗

次の担当: 案件を次に動かす社員1人。
避ける: 担当者、責任者

停滞: 状況が7日以上変わっていない案件。
避ける: 遅延、放置
